Configurer le cloud Recover

Cette étape connecte Recover à votre propre projet Supabase. Après configuration, les comptes, achats, dossiers et documents pourront être synchronisés entre vos appareils.

1. Préparer Supabase

Créez un projet Supabase, ouvrez SQL Editor, puis exécutez le fichier fourni ci-dessous.

Télécharger le SQL Recover

2. Créer ou connecter votre compte

Une fois la configuration enregistrée, ouvrez la page de connexion Recover.

Ouvrir la connexion
🔒 Important

Ne collez jamais une clé service_role ou une clé secrète ici. Recover côté navigateur doit utiliser uniquement une clé publique/publishable (ou anon), tandis que les règles RLS protègent les données.
